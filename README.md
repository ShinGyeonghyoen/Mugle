# Mugle 2

Mobile-first lunch decision app with Mogu character reactions, menu recommendations, local meal history, PWA support, and mini games.

## Structure

```text
.
|-- public/          # Images, icons, manifest assets
|-- src/             # App source
|-- index.html
|-- package.json
|-- package-lock.json
|-- tsconfig.json
`-- vite.config.ts
```

`node_modules/` and `dist/` are generated folders and should not be committed.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
